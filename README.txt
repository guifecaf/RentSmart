O RentSmart é um programa em Python para calcular orçamentos de aluguel de casas, apartamentos e estúdios. Ele considera os adicionais, os descontos e o parcelamento da taxa do contrato.

COMO EXECUTAR

1. Tenha o Python instalado no computador.
2. Abra o terminal na pasta do projeto.
3. Execute o comando: python rentsmart.py
   No Windows, também pode usar: py rentsmart.py
4. Responda às perguntas que aparecem na tela.

Ao finalizar, o programa mostra o orçamento e gera o arquivo projecao_locacao.csv com a previsão dos pagamentos dos 12 meses.
